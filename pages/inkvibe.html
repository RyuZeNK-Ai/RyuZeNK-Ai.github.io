¿Qué es InkVibe?

InkVibe es una plataforma FullStack en producción para la industria del tatuaje, diseñada para conectar artistas, estudios y clientes en un ecosistema digital integrado.

La plataforma permite a artistas gestionar su portafolio profesional, a estudios administrar su equipo y agenda, y a clientes explorar artistas, solicitar cotizaciones, hacer reservas y gestionar pagos — todo en un solo lugar.

Mi contribución principal: Inicié el backend desde cero, diseñé la arquitectura del sistema, implementé más de 60 endpoints REST documentados con Swagger y evolucioné desde Backend Developer hasta la coordinación técnica del proyecto completo.

Spec Driven Development (SDD)

📋 Especificación primero

Antes de escribir código, el comportamiento de cada endpoint se define en documentos de spec: rutas, payloads, validaciones, respuestas y casos de error acordados entre todos los equipos.

Resultado: Cero ambigüedades entre Backend, Frontend y Mobile.

⚙️ Implementación contra spec

El código se construye para cumplir la spec, no al revés. NestJS + TypeScript + Swagger garantizan que la API implementada refleja exactamente el contrato definido.

Resultado: APIs predecibles, testeables y documentadas.

✅ Validación y coordinación

Los tests verifican cumplimiento contra la spec original. El contrato es la fuente de verdad para todos los equipos, facilitando la revisión técnica y el onboarding.

Resultado: Coordinación fluida entre todos los equipos del proyecto.
