**Portafolio profesional de Nicolás Peña** - Desarrollador Fullstack especializado en aplicaciones web completas e integración de IA Generativa.

## 📋 ¿Para qué sirve?

- **Mostrar proyectos** de desarrollo Fullstack funcionales en producción
- **Exhibir creaciones** con IA Generativa (imágenes, personajes, conceptos)
- **Contacto profesional** con clientes y empleadores
- **Demostrar habilidades** técnicas y creativas en un solo lugar

## 🛠️ Tecnologías

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Diseño**: Responsive Design, Animations, Neón Effects
- **Hosting**: GitHub Pages
- **Herramientas**: Font Awesome, Google Fonts, Custom CSS

## 🎨 Características principales

- **Diseño futurista** con efectos neón personalizados

## 🚀 Cómo usar

1. Clonar el repositorio:
```bash
git clone https://github.com/RyuZeNK-Ai/RyuZeNK-Ai.github.io.git
```

2. Abrir `index.html` en el navegador o usar un servidor local:
```bash
python -m http.server 8000
```

3. Navegar a `http://localhost:8000`
